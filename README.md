# SSMC Wiki App

Интерактивные инструменты для вики Space Stories: Marine Corps.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Приложение получает актуальный каталог снаряжения из репозитория
`DeferW/ssmc-wiki-data` при открытии страницы. Оружейные кейсы автоматически
раскрываются, а карточки используют готовые игровые спрайты.
