# SSMC Wiki

SSMC Wiki — неофициальная модульная база данных и набор веб-инструментов для
**Space Stories Marine Corps**. Проект разделён на два репозитория:
[`ssmc-wiki-data`](https://github.com/DeferW/ssmc-wiki-data) собирает данные из
исходников игры, а [`ssmc-wiki-app`](https://github.com/DeferW/ssmc-wiki-app)
показывает их пользователю.

- [Планы и TODO](https://github.com/DeferW/ssmc-wiki-app/blob/main/docs/ROADMAP.md)
- [Руководство контрибьютора](https://github.com/DeferW/ssmc-wiki-app/blob/main/docs/CONTRIBUTOR_GUIDE.md)

## Этот репозиторий

`ssmc-wiki-app` — React-приложение, которое загружает опубликованные контракты
из `ssmc-wiki-data` и превращает их в независимые пользовательские модули. Сайт
не разбирает игровые YAML и не зависит от внутренних отчётов сборщика.

## Архитектура

```text
data/<module>/ публичный контракт
          ↓
config + loader + TypeScript types
          ↓
чистые преобразования и предметная логика
          ↓
страница и компоненты модуля
          ↓
общая оболочка, router и registry
```

```text
src/modules/<module-id>/   изолированная реализация модуля
src/modules/registry.tsx   карточки, статусы и маршруты модулей
src/pages/                 общие страницы приложения
src/admin/                 отдельная граница административных функций
src/styles/                тема, экранные и адаптивные стили
public/                    статические файлы, не получаемые из data
```

Новый модуль создаётся непосредственно в `src/modules/<module-id>/` и
регистрируется в `src/modules/registry.tsx`. Registry подключает модуль к
оболочке, но не содержит его бизнес-логику.

Каждый модуль сам владеет загрузкой и проверкой своего контракта, типами,
вычислениями, состоянием и интерфейсом. Межмодульное переиспользование допускается
только через небольшую устойчивую границу; общая абстракция появляется после
второго реального применения.

Сайт принимает только явно поддерживаемые `schemaVersion`. Ломающее изменение
данных публикуется в `ssmc-wiki-data` раньше, чем приложение начинает его
требовать.
