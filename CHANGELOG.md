# Изменения

Записи видны игрокам на странице «Проект». Файл не редактируется вручную:
новые разделы добавляет `npm run release` из отметок в
[.changes/](.changes/README.md). Правила нумерации — в
[docs/VERSIONING.md](docs/VERSIONING.md).

## 3.1.0 — 2026-09-15

Обновление «3.1 astra update» и доработки после него.

- Урон: вкладка «Отдача» — разброс выбранной сборки, режимы огня и хват
  оружия, точность снарядов и уклонение ксеносов.
- Карты: точки неактивных инсертов видны полупрозрачными, в карточке точки
  указаны инсерт и шанс его появления.
- Карты: быстрее загружаются при приближении — сначала видимая область,
  уже загруженная детализация не пропадает, сбои загрузки повторяются сами.
- Сайт: кнопка с булавкой открывает текущую страницу в окне поверх других
  окон, удобно держать рядом с игрой.
- Сайт: одинаковый шрифт и элементы управления в Chrome и Firefox.
- Сайт: разделы открываются быстрее — каждый загружается только при переходе
  в него.

## 3.0.0 — 2026-09-04

Выпуск RELEASE 3.0: каталог снаряжения, игровые карты, химический
планировщик и калькулятор урона. Более ранние версии не записывались.
