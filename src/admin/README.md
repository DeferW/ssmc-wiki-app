# Административная зона

Тестовый редактор каталога находится на маршруте `/module/equipment/admin` и отделён от
публичного модуля каталога. Страницу и локальное редактирование может открыть
любой пользователь; пароль требуется только для записи `catalog-overrides.json`
через Cloudflare Worker.

Файл хранится в `ssmc-wiki-app/config/catalog-overrides.json`. Worker и его
GitHub token должны читать и перезаписывать именно этот репозиторий и путь;
сборщик данных overrides больше не применяет.

## Как устроено редактирование

1. Клиент загружает overrides и SHA текущего файла из `ssmc-wiki-app` через
   публичный GitHub Contents API.
2. Запись с паролем выполняется через Worker с проверкой этого SHA.
3. Изменения сразу применяются к интерфейсу и сохраняются локально в браузере.
4. Категория, совпадающая с `classification.automaticCategory`, удаляет запись
   предмета из overrides.
5. Сохранение отправляет полный документ schema v2 вместе с SHA и полностью
   перезаписывает файл. Пароль хранится только в состоянии текущей страницы.

`Скрытые` — обычная категория override, а не поле `hidden`. В публичной выдаче
такие предметы не показываются, но остаются в `catalog.items`, поэтому карточка
может быть открыта из связей другого предмета.

## Обязательная правка Worker

Нулевой по размеру `catalog-overrides.json` — допустимый пустой конфиг. В
`getOverrides` содержимое нужно проверять до `JSON.parse`:

```js
const text = decodeBase64Utf8(result.file.content);
const overrides = text.trim()
  ? JSON.parse(text)
  : { schemaVersion: 2, items: {} };
```

Для отсутствующего файла Worker также должен возвращать канонический пустой
документ `{ schemaVersion: 2, items: {} }`. Это сохраняет SHA существующего
пустого файла и позволяет безопасно перезаписать его без конфликта.

## Граница безопасности

Текущий режим намеренно является тестовым: HTML административной страницы
публичен, а сервер защищает только операцию записи. Для будущей закрытой версии
нужны серверная сессия HttpOnly/Secure/SameSite, проверка сессии до возврата
страницы и данных, CSRF-защита, rate limiting и журнал изменений.
