# Admin boundary

Будущая административная версия должна подключаться здесь как отдельный модуль
и отдельный защищённый маршрут. Публичное приложение не импортирует код из этой
папки и не показывает ссылку на административную страницу.

Клиентская проверка пароля не считается защитой. Для реализации понадобятся:

1. серверная проверка пароля;
2. короткоживущая HttpOnly/Secure/SameSite-сессия;
3. проверка сессии до возврата административной страницы и данных;
4. CSRF-защита, rate limiting и журнал изменений;
5. отдельный API с минимальными правами на изменение overrides.
