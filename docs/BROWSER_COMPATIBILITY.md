# Одинаковое оформление в Chromium и Firefox

Сайт поставляет IBM Plex Mono 5.3.0 (Fontsource) локально, включая кириллицу,
латиницу, начертания 400–700 и курсив. Лицензия SIL OFL сохранена рядом с файлами
в `src/assets/fonts/OFL.txt`. Шрифты для canvas загружаются до первого рендера,
чтобы кэш подписей карты не сохранял запасной системный шрифт.

Общие правила находятся в `src/styles/base.css` и `src/styles/controls.css`.
Последний файл подключается после стилей модулей: оформление ползунков,
закрытых select и размеров ручек должно оставаться общим. Псевдоэлементы
WebKit и Mozilla описываются отдельными правилами. Числовые поля сохраняют
управление стрелками клавиатуры, хотя нативные кнопки изменения числа скрыты.

Проверка 2026-09-14: Playwright, Windows, Chromium 151.0.7922.34 и Firefox 153.0,
viewport 1440×900 и 390×844, DPR 1. Главная, оборудование, химия, урон и карты:
20 загрузок без ошибок JavaScript и горизонтального переполнения. После
загрузки шрифтов сравнивались первые 35 элементов header/main/h1/input/select/button
с ненулевой шириной на каждой странице. Различий координат и размеров больше
1 CSS-пикселя не обнаружено. Это выборочная проверка геометрии, не попиксельная
гарантия для всех состояний интерфейса. Ползунок, число, checkbox и select
дополнительно проверены через ввод и клавиатуру в обоих движках.

Сглаживание текста, системное меню раскрытого select и полосы прокрутки могут
отличаться в зависимости от движка, ОС и пользовательских настроек. Сравнивать
нужно при одинаковых viewport, масштабе страницы и масштабе ОС. Нативные меню
выбора сохранены для доступности и привычного управления с клавиатуры.
