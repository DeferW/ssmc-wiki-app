# Отметки изменений

Каждый PR, изменение которого заметно пользователю сайта, добавляет сюда один
файл `.md` с любым понятным именем, например `roof-tiers.md`:

```markdown
---
bump: minor
---
Карты: заливка зон по уровням крыши (1–4) с отдельными переключателями.
```

- `bump` — тип изменения: `major`, `minor` или `patch`. Как выбрать — в
  [docs/VERSIONING.md](../docs/VERSIONING.md).
- Текст — одна строка для журнала изменений. Её видят игроки на странице
  «Проект», поэтому пишите о том, что изменилось на сайте, а не в коде.

Рефакторинг, тесты, документация и CI отметок не требуют.

Отметки показываются на странице «Проект» как «Не выпущено». Команда
`npm run release` превращает их в новую версию: считает номер, переносит текст в
[CHANGELOG.md](../CHANGELOG.md) и удаляет использованные файлы. Этот README
команда не трогает.
